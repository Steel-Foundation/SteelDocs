## Command Development in SteelMC

Commands in SteelMC are designed to be very similar to how they are in Minecraft. This guide will teach
you where and how to define commands.

## Available Guides

- [**Creating Commands**](../01-commands) - Learn how to register and create basic commands
- [**Command Arguments**](../02-arguments) - Learn how argument types are defined and how to create new ones
- [**Command Suggestions**](../03-suggestions) - Learn how to provide suggestions for arguments
- [**Command Permissions**](../04-permissions) - Learn how permissions are defined and created
