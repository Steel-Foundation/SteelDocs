---
title: أعلام الميزات (Feature Flags)
description: مرجع شامل لأعلام الترجمة البرمجية في SteelMC.
---

يستخدم SteelMC أعلام ميزات Rust لتفعيل أو تعطيل وظائف معينة أثناء وقت الترجمة البرمجية (Compile-time). تتيح لك هذه الأعلام تخصيص الخادم للإنتاج، التنقيح، تحليل الأداء، أو جمع القياسات عن بُعد.

يقوم معظم المستخدمين ببناء ملف الخادم التنفيذي عبر حزمة `steel`:

```bash
cargo build -p steel --features "feature_name"
```

## حزمة steel

تتحكم هذه الأعلام في الملف التنفيذي الرئيسي للخادم.

| الميزة | افتراضياً | الوصف |
| :--- | :--- | :--- |
| `mimalloc` | نعم | استخدام MiMalloc كمخصص ذاكرة عام لتحسين سرعة حجز الذاكرة. |
| `stand-alone` | لا | تضمين الأيقونة الافتراضية وكتابتها عند عدم توفر ملف الأيقونة المحدد. |
| `deadlock_detection` | لا | تفعيل كشف حالات التعليق والـ Deadlock عبر `parking_lot` لأغراض التنقيح. |
| `dhat-heap` | لا | تفعيل أداة تحليل الذاكرة DHAT، وتحل محل MiMalloc عند تفعيل كليهما. |
| `spawn_chunk_display` | لا | إظهار شبكة ملونة في وحدة التحكم أثناء توليد Chunks منطقة البداية (Spawn Chunks). |
| `slow_chunk_gen` | لا | إبطاء توليد الـ Chunks أثناء تحضير البداية لتسهيل متابعة الرسم البياني. |
| `jaeger` | لا | تفعيل تصدير تتبع OpenTelemetry عبر OTLP لمنظومة Jaeger. |

### أمثلة الاستخدام

```bash
# البناء مع تفعيل كشف أقفال المزامنة
cargo build -p steel --features deadlock_detection

# البناء بدون مخصص MiMalloc الافتراضي
cargo build -p steel --no-default-features

# البناء مع إظهار شبكة الـ Spawn Chunks
cargo build -p steel --features "spawn_chunk_display slow_chunk_gen"

# البناء مع دعم التتبع عبر Jaeger/OpenTelemetry
cargo build -p steel --features jaeger
```

## حزمة steel-core

تتحكم هذه الأعلام في منطق اللعبة الأساسي ومساعدات التنقيح منخفضة المستوى.

| الميزة | افتراضياً | الوصف |
| :--- | :--- | :--- |
| `stand-alone` | لا | معرفة في ملف الحزمة، وتتعامل مع سلوك الأيقونة المضمنة. |
| `slow_chunk_gen` | لا | إضافة تأخير بسيط بعد مراحل توليد الـ Chunks. |
| `flint` | لا | إتاحة مساعدات فحص سلوكيات البلوكات والعناصر وأسماء الأنواع. |

## حزمة steel-registry

تتحكم هذه الأعلام في نظام سجلات اللعبة والكود المولد تلقائياً.

| الميزة | افتراضياً | الوصف |
| :--- | :--- | :--- |
| `fmt` | لا | تشغيل `rustfmt` على ملفات السجلات المولدة أثناء سكربت البناء. |
| `minecraft-src` | لا | تفعيل مساعدات مقارنة بيانات السجلات المولدة مع بيانات مرجع `minecraft-src`. |

## حزمة steel-utils

| الميزة | افتراضياً | الوصف |
| :--- | :--- | :--- |
| `fmt` | لا | تشغيل `rustfmt` على ملفات الأدوات المولدة. |

## حزمة steel-worldgen

| الميزة | افتراضياً | الوصف |
| :--- | :--- | :--- |
| `fmt` | لا | تشغيل `rustfmt` على ملفات توليد العوالم المولدة. |

## الجمع بين عدة ميزات

يمكنك تفعيل ميزات متعددة في أمر بناء واحد:

```bash
# البناء مع ميزات تنقيح متعددة
cargo build -p steel --features "deadlock_detection spawn_chunk_display slow_chunk_gen"

# البناء لتوزيع خادم مستقل
cargo build -p steel --release --features stand-alone

# تنسيق مخرجات السجلات المولدة أثناء بناء تلك الحزمة
cargo build -p steel-registry --features fmt
```

أعلام الميزات مرتبطة بالحزم؛ عند تفعيل ميزة لحزمة أخرى غير `steel`، حدد الحزمة صراحة باستخدام `-p`.

## توصيات بيئة الإنتاج

بالنسبة لخوادم الإنتاج الفعلية، نوصي بما يلي:

- الإبقاء على `mimalloc` مفعلاً إلا إذا كنت تقوم بتحليل الذاكرة عبر `dhat-heap`.
- إبقاء كل من `deadlock_detection`, `dhat-heap`, `spawn_chunk_display`, و `slow_chunk_gen` معطلة.
- تفعيل `stand-alone` فقط إذا كنت تريد أن يوفر الملف التنفيذي أيقونة الخادم الافتراضية تلقائياً.
- تفعيل `jaeger` فقط عندما يكون لديك مجمع تتبع OTLP نشط.
- استخدام `fmt` و `minecraft-src` لأغراض التطوير وفحص الكود المولد فقط.
