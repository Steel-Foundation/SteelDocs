注册表（Registry）是 Minecraft 架构的核心骨架。方块、物品、生物群系、实体类型、音效以及附魔等几乎所有游戏对象均通过注册表统一管理与寻址。

SteelMC 在 Rust 中设计了一套零运行时开销、强类型且兼顾未来模组扩展的注册表体系。

## 核心设计理念

- **编译期常量寻址**：原版已知的内置条目（如 `minecraft:stone`）直接生成静态枚举或常量标识符，避免哈希查找开销。
- **动态扩展支持**：数据包自定义内容（动态生物群系、自定义维度等）支持在服务端运行时动态加载与注册。
- **协议 ID 自动同步** ：原版网络通信要求客户端与服务端就每个条目的 Raw ID（协议整数 ID）保持一致，注册表系统负责双向映射。

## 代码生成流程

注册表定义通过 build.rs 构建脚本根据 `build_assets/` 中的 JSON 数据自动生成 Rust 源码，输出至目标编译目录中。
