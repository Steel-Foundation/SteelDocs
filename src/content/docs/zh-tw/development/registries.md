註冊表（Registry）是 Minecraft 架構的核心骨架。方塊、物品、生態域、實體類型、音效以及附魔等幾乎所有遊戲物件均透過註冊表統一管理與尋址。

SteelMC 在 Rust 中設計了一套零執行期開銷、強型別且兼顧未來模組擴充的註冊表體系。

## 核心設計理念

- **編譯期常數尋址**：原版已知的內建項目（如 `minecraft:stone`）直接產生靜態列舉或常數識別碼，避免雜湊查找開銷。
- **動態擴充支援**：資料包自訂內容（動態生態域、自訂維度等）支援在伺服器執行期動態載入與註冊。
- **通訊協定 ID 自動同步** ：原版網路通訊要求用戶端與伺服器就每個項目的 Raw ID（協定整數 ID）保持一致，註冊表系統負責雙向對應。

## 程式碼產生流程

註冊表定義透過 build.rs 建置腳本根據 `build_assets/` 中的 JSON 資料自動產生 Rust 原始碼，輸出至目標編譯目錄中。
