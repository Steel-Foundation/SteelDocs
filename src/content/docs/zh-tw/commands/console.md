當你在終端機中執行 SteelMC 時，主控台同時也是一個功能完整的互動式命令列。日誌輸出會在底部的輸入行上方捲動，你在輸入行中輸入的指令將以主控台發送者（Console Sender）身分執行，並自動略過所有玩家權限檢查。

## 關閉伺服器

| 快捷鍵   | 行為說明                                       |
| -------- | ---------------------------------------------- |
| `Ctrl+C` | 當輸入行為空時，觸發優雅關閉伺服器             |
| `Ctrl+Q` | 無論輸入行中是否有內容，立即觸發優雅關閉伺服器 |

按下 `Ctrl+C` 時會依以下順序判斷：

1. 若目前有選取的文字，則複製選取文字。
2. 若輸入行中有尚未執行的文字，則清空目前輸入行。
3. 若輸入行已經為空，則開始優雅關閉伺服器。

因此，如果你在輸入指令到一半時想要關閉伺服器，可以連續按兩次 `Ctrl+C`，或者直接按一次 `Ctrl+Q`。

執行 `stop` 指令同樣會關閉伺服器。所有關閉途徑都會走同一套優雅關閉流程：在程序結束前完整儲存所有世界存檔與玩家資料，並將主控台指令歷史紀錄寫入磁碟。

### 作業系統信號處理

當作業系統要求程序停止時（例如作為系統服務執行、在 Docker 容器中停止或無互動式終端機時），SteelMC 同樣會執行優雅關閉：

| 平台    | 攔截處理的信號 / 事件                                      |
| ------- | ---------------------------------------------------------- |
| Unix    | `SIGINT`、`SIGTERM`、`SIGHUP`                              |
| Windows | `Ctrl+C`、`Ctrl+Break`、關閉主控台視窗、使用者登出、系統關機 |

只有第一個停止信號會啟動關閉存檔流程；在存檔完成之前，後續重複傳送的信號會被忽略，因此多按一次 `Ctrl+C` 不會中斷正在進行的存檔寫入。

:::caution
`SIGKILL`（`kill -9`）或透過工作管理員強制結束程序無法被攔截處理，尚未寫入磁碟的資料將會遺失。
:::

## 編輯輸入行

| 快捷鍵                 | 行為說明                                           |
| ---------------------- | -------------------------------------------------- |
| `Enter`                | 執行目前輸入的指令                                 |
| `Left` / `Right`       | 左右移動游標                                       |
| `Home` / `End`         | 跳至行首或行尾                                     |
| `Backspace` / `Delete` | 刪除游標前或游標後的字元                           |
| `Insert`               | 切換覆寫輸入模式（啟用時游標變為實心方塊）         |
| `Esc`                  | 清空目前輸入行                                     |

## 文字選取與複製

| 快捷鍵                       | 行為說明                               |
| ---------------------------- | -------------------------------------- |
| `Shift+Left` / `Shift+Right` | 向左或向右逐字元擴展／縮小選取範圍     |
| `Shift+Home`                 | 從目前游標位置選取至行首               |
| `Shift+End`                  | 從目前游標位置選取至行尾               |
| `Ctrl+A`                     | 全選整行輸入                           |
| `Ctrl+C`                     | 複製目前選取範圍內容                   |
| `Ctrl+X`                     | 剪下目前選取範圍內容                   |

在有選取範圍時直接輸入字元、按 `Backspace` 或 `Delete` 會替換或刪除選取的文字；按 `Left` 或 `Right` 則會取消選取並將游標移至選取範圍的起點或終點。

複製功能基於終端機的 OSC 52 跳脫序列實作，因此需要終端機本身支援 OSC 52（例如 kitty、WezTerm、Alacritty、iTerm2、Windows Terminal 等）。部分終端機或多工器（如 `tmux`）可能需要手動開啟 OSC 52 剪貼簿存取權限。貼上文字請直接使用終端機本身的貼上快捷鍵。

:::note
`Ctrl+C` 僅在有文字被選取時執行複製；若未選取文字，則會清空輸入行（輸入行已空時則觸發關閉伺服器）。
:::

## 指令歷史紀錄

| 快捷鍵            | 行為說明         |
| ----------------- | ---------------- |
| `Up` / `Ctrl+P`   | 上一筆歷史指令   |
| `Down` / `Ctrl+N` | 下一筆歷史指令   |
| `Ctrl+R`          | 反向搜尋歷史指令 |

指令歷史紀錄儲存在[日誌目錄](../../configuration/server-configuration)（`log.log_path`，預設為 `./.logs`）下的 `history.txt` 檔案中，跨重啟持久保留。主控台最多保留最近 `log.max_history` 筆指令（預設為 `50` 筆）。

### 反向搜尋歷史指令（Reverse Search）

按下 `Ctrl+R` 可像在 Bash 中一樣往回搜尋指令歷史。此時提示字元會變為搜尋狀態：

```text
(reverse-i-search)`give': give @s diamond 64
```

隨著你輸入關鍵字，輸入行會即時顯示包含該關鍵字的最新一筆歷史指令，並醒目提示符合的部分。若沒有符合結果，提示字元會顯示 `failed reverse-i-search`，並在畫面上保留上一次符合的指令。

| 快捷鍵                      | 行為說明                                         |
| --------------------------- | ------------------------------------------------ |
| `Ctrl+R`                    | 跳至上一筆更早的符合指令                         |
| `Backspace`                 | 刪除搜尋關鍵字的最後一個字元                     |
| `Enter`                     | 直接執行目前符合的指令                           |
| `Tab`                       | 將符合的指令保留在輸入行中以便繼續編輯           |
| `Esc` / `Ctrl+C` / `Ctrl+G` | 取消搜尋並還原搜尋前輸入行中原有的內容           |

按下方向鍵或 `Home` 等其他導覽鍵同樣會將目前符合的指令保留在輸入行中，並立即執行對應的游標移動操作。選取某筆歷史指令後，按 `Up` 和 `Down` 會從該筆指令所在的歷史位置繼續往上或往下翻閱。

## 指令自動補全（Tab Completion）

按下 `Tab` 鍵可叫出目前指令的自動補全建議清單。當補全清單開啟時：

| 快捷鍵            | 行為說明                               |
| ----------------- | -------------------------------------- |
| `Up` / `Ctrl+P`   | 往上選取上一筆補全建議                 |
| `Down` / `Ctrl+N` | 往下選取下一筆補全建議                 |
| `Tab`             | 插入目前選取的補全內容並關閉建議清單   |

補全清單會隨著你繼續輸入字元或移動游標而即時更新。
