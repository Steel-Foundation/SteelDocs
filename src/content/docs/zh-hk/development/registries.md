註冊表（Registry）係 Minecraft 架構嘅核心骨架。方塊、物品、生物群系、實體類型、音效以及附魔等幾乎所有遊戲對象均透過註冊表統一管理與尋址。

SteelMC 喺 Rust 入面設計咗一套零運行時開銷、強類型且兼顧未來模組擴展嘅註冊表體系。

## 核心設計理念

- **編譯期常量尋址**：原版已知嘅內置條目（如 `minecraft:stone`）直接生成靜態列舉或常量標識符，避免雜湊查找開銷。
- **動態擴展支援**：數據包自訂內容（動態生物群系、自訂維度等）支援喺伺服器運行時動態載入與註冊。
- **網絡協議 ID 自動同步** ：原版網絡通信要求客戶端與伺服器就每個條目嘅 Raw ID（協議整數 ID）保持一致，註冊表系統負責雙向映射。

## 程式碼生成流程

註冊表定義透過 build.rs 建置腳本根據 `build_assets/` 入面嘅 JSON 數據自動生成 Rust 源碼，輸出至目標編譯目錄中。
