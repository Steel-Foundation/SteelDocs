當你喺終端機運行 SteelMC 時，控制台同時亦係一個功能完備嘅互動式命令列。日誌輸出會喺底部嘅輸入行上方滾動，你喺輸入行入面輸入嘅指令將以控制台發送者（Console Sender）身份執行，並自動跳過所有玩家權限檢查。

## 關閉伺服器

| 快捷鍵   | 行為說明                                       |
| -------- | ---------------------------------------------- |
| `Ctrl+C` | 當輸入行為空時，觸發優雅熄服                   |
| `Ctrl+Q` | 無論輸入行入面有冇內容，立即觸發優雅熄服       |

撳 `Ctrl+C` 時會按以下順序依次判斷：

1. 如果目前有選中嘅文字，則複製選中文字。
2. 如果輸入行入面有尚未執行嘅文字，則清空目前輸入行。
3. 如果輸入行已經為空，則開始優雅關閉伺服器。

因此，如果你喺輸入指令到一半時想熄服，可以連續撳兩次 `Ctrl+C`，或者直接撳一次 `Ctrl+Q`。

執行 `stop` 指令同樣會關閉伺服器。所有熄服途徑都會行同一套優雅熄服流程：喺進程退出前完整保存所有世界存檔與玩家數據，並將控制台指令歷史記錄寫入磁碟。

### 作業系統信號處理

當作業系統要求進程停止時（例如作為系統服務運行、喺 Docker 容器入面停止或無互動式終端機時），SteelMC 同樣會執行優雅熄服：

| 平台    | 捕獲處理嘅信號 / 事件                                      |
| ------- | ---------------------------------------------------------- |
| Unix    | `SIGINT`、`SIGTERM`、`SIGHUP`                              |
| Windows | `Ctrl+C`、`Ctrl+Break`、關閉控制台視窗、用戶登出、系統關機 |

只有第一個停止信號會啟動熄服保存流程；喺存檔保存完成之前，後續重複發送嘅信號會被忽略，因此多撳一次 `Ctrl+C` 唔會中斷正在進行嘅存檔寫入。

:::caution
`SIGKILL`（`kill -9`）或透過工作管理員強制結束進程無法被程式捕獲處理，尚未寫入磁碟嘅數據將會遺失。
:::

## 編輯輸入行

| 快捷鍵                 | 行為說明                                           |
| ---------------------- | -------------------------------------------------- |
| `Enter`                | 執行目前輸入嘅指令                                 |
| `Left` / `Right`       | 左右移動游標                                       |
| `Home` / `End`         | 跳到行首或行尾                                     |
| `Backspace` / `Delete` | 刪除游標前或游標後嘅字元                           |
| `Insert`               | 切換覆寫輸入模式（啟用時游標變為實心方塊）         |
| `Esc`                  | 清空目前輸入行                                     |

## 文字選取與複製

| 快捷鍵                       | 行為說明                               |
| ---------------------------- | -------------------------------------- |
| `Shift+Left` / `Shift+Right` | 向左或向右逐字元擴展／收縮選取範圍     |
| `Shift+Home`                 | 由目前游標位置選取到行首               |
| `Shift+End`                  | 由目前游標位置選取到行尾               |
| `Ctrl+A`                     | 全選成行輸入                           |
| `Ctrl+C`                     | 複製目前選取範圍內容                   |
| `Ctrl+X`                     | 剪下目前選取範圍內容                   |

喺有選取範圍時直接輸入字元、撳 `Backspace` 或 `Delete` 會替換或刪除選中嘅文字；撳 `Left` 或 `Right` 則會取消選取並將游標移至選取範圍嘅起點或終點。

複製功能基於終端機嘅 OSC 52 轉義序列實現，因此需要終端機本身支援 OSC 52（例如 kitty、WezTerm、Alacritty、iTerm2、Windows Terminal 等）。部分終端機或終端複用器（如 `tmux`）可能需要手動開啟 OSC 52 剪貼簿存取權限。貼上文字請直接使用終端機自身嘅貼上快捷鍵。

:::note
`Ctrl+C` 僅喺有文字被選中時執行複製；若未選中文字，則會清空輸入行（輸入行已空時則觸發熄服）。
:::

## 指令歷史記錄

| 快捷鍵            | 行為說明         |
| ----------------- | ---------------- |
| `Up` / `Ctrl+P`   | 上一條歷史指令   |
| `Down` / `Ctrl+N` | 下一條歷史指令   |
| `Ctrl+R`          | 反向搜尋歷史指令 |

指令歷史記錄保存喺[日誌目錄](../../configuration/server-configuration)（`log.log_path`，預設為 `./.logs`）下嘅 `history.txt` 檔案入面，跨重啟持久保留。控制台最多保留最近 `log.max_history` 條指令（預設為 `50` 條）。

### 反向搜尋歷史指令（Reverse Search）

撳 `Ctrl+R` 可以好似喺 Bash 入面咁向後搜尋指令歷史。呢個時候提示符會變為搜尋狀態：

```text
(reverse-i-search)`give': give @s diamond 64
```

隨住你輸入關鍵字，輸入行會即時展示包含該關鍵字嘅最新一條歷史指令，並高亮顯示匹配部分。如果冇匹配結果，提示符會顯示 `failed reverse-i-search`，並喺畫面上保留上一次匹配嘅指令。

| 快捷鍵                      | 行為說明                                         |
| --------------------------- | ------------------------------------------------ |
| `Ctrl+R`                    | 跳到上一條更早嘅匹配指令                         |
| `Backspace`                 | 刪除搜尋關鍵字嘅最後一個字元                     |
| `Enter`                     | 直接執行目前匹配到嘅指令                         |
| `Tab`                       | 將匹配嘅指令保留喺輸入行入面以便繼續編輯         |
| `Esc` / `Ctrl+C` / `Ctrl+G` | 取消搜尋並還原搜尋前輸入行入面原有嘅內容         |

撳方向鍵或 `Home` 等其他導航鍵同樣會將目前匹配嘅指令保留喺輸入行入面，並立即執行對應嘅游標移動操作。選中某條歷史指令後，撳 `Up` 同 `Down` 會由該條指令所在嘅歷史位置繼續向上或向下翻閱。

## 指令自動補全（Tab Completion）

撳 `Tab` 鍵可以叫出目前指令嘅自動補全建議列表。當補全列表打開時：

| 快捷鍵            | 行為說明                               |
| ----------------- | -------------------------------------- |
| `Up` / `Ctrl+P`   | 向上高亮選擇上一條補全建議             |
| `Down` / `Ctrl+N` | 向下高亮選擇下一條補全建議             |
| `Tab`             | 插入目前高亮嘅補全內容並關閉建議列表   |

補全列表會隨住你繼續輸入字元或移動游標而即時更新。
